# Context — Det Digitale Atelier 360-Degree Review

## Background
"Det Digitale Atelier" is a Next.js application designed to showcase styling lookbooks. The application is built using React, Tailwind CSS, Framer Motion, and Lucide React. It provides key features like:
- Carousel component showcasing looks
- ColorSlider for choosing color themes (glow, analog, monochrome)
- QuietInput for styling preference entry
- Styling advice engine (`stylingLogic.ts`)
